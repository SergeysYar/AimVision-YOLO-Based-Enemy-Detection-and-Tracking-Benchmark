# Математическая модель

## 1. Постановка задачи детекции
Для изображения \(I \in \mathbb{R}^{H \times W \times 3}\) детектор \(f_\theta\) предсказывает:
- вероятность класса,
- ограничивающий прямоугольник \(b=(x_1,y_1,x_2,y_2)\),
- confidence \(s \in [0,1]\).

Детекция:
\[
d_i=(b_i,c_i,s_i)
\]

## 2. Представление bbox
- Углы: \((x_1,y_1,x_2,y_2)\)
- Центр/размер: \((x_c,y_c,w,h)\)

\[
x_c=\frac{x_1+x_2}{2},\quad y_c=\frac{y_1+y_2}{2},\quad w=x_2-x_1,\quad h=y_2-y_1
\]

## 3. Confidence score
\[
s=p(\text{object}) \cdot p(c\mid \text{object})
\]
Детекции ниже порога \(\tau\) отбрасываются.

## 4. IoU
\[
\text{IoU}(A,B)=\frac{|A \cap B|}{|A \cup B|}
\]
Чем выше IoU, тем сильнее пересечение боксов.

## 5. Non-Maximum Suppression
Сортируем по confidence, оставляем лучший бокс, подавляем боксы с IoU выше порога \(\tau_{nms}\), повторяем.

## 6. Tracking-by-Detection
На кадре \(t\):
1. Детекции \(D_t\)
2. Прогноз треков \(\hat{T}_t\)
3. Сопоставление детекций и треков
4. Обновление треков, создание новых, старение пропущенных

## 7. Идея Kalman filter (SORT)
\[
\mathbf{x}_t=[x_c,y_c,w,h,\dot{x}_c,\dot{y}_c,\dot{w},\dot{h}]^\top
\]
\[
\mathbf{x}_{t|t-1}=\mathbf{F}\mathbf{x}_{t-1|t-1}
\]
Обновление состояния по измерению \(\mathbf{z}_t\).

## 8. Hungarian matching
Матрица стоимости:
\[
C_{ij}=1-\text{IoU}(\hat{b}_i,b_j)
\]
Далее решается задача минимального паросочетания.

## 9. Прогноз скорости
\[
\hat{x}_{c,t}=x_{c,t-1}+\dot{x}_{c,t-1},\quad
\hat{y}_{c,t}=y_{c,t-1}+\dot{y}_{c,t-1}
\]
Помогает сохранить ID при кратких окклюзиях.

## 10. Варианты функции стоимости
\[
C_{ij}^{IoU}=1-\text{IoU}_{ij},\quad
C_{ij}^{dist}=||\mathbf{m}_i-\mathbf{m}_j||_2
\]
где \(\mathbf{m}\) — центр объекта.
