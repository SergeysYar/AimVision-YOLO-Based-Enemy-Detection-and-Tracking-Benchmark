# Математическая модель

Эта версия написана без LaTeX-рендера, чтобы формулы корректно отображались в GitHub.

## 1. Формализация детекции
Вход:
- `I` размера `H x W x 3`

Выход детектора для объекта `i`:
- `b_i = (x1, y1, x2, y2)` — bbox
- `c_i` — класс
- `s_i` — confidence в диапазоне от 0 до 1

Запись детекции:
```text
d_i = (b_i, c_i, s_i)
```

## 2. Представление bounding box
Два формата:
- Угловой: `(x1, y1, x2, y2)`
- Центр/размер: `(xc, yc, w, h)`

Преобразование:
```text
xc = (x1 + x2) / 2
yc = (y1 + y2) / 2
w  = x2 - x1
h  = y2 - y1
```

## 3. Confidence score
Типичная интерпретация:
```text
s = P(object) * P(class | object)
```
Если `s` меньше порога, детекция отбрасывается.

## 4. IoU (Intersection over Union)
Для боксов `A` и `B`:
```text
IoU(A, B) = area(A ∩ B) / area(A ∪ B)
```
Значение от 0 до 1. Чем больше, тем лучше пересечение.

## 5. NMS (Non-Maximum Suppression)
1. Отсортировать боксы по confidence.
2. Оставить бокс с максимальным confidence.
3. Удалить боксы с IoU выше `nms_threshold`.
4. Повторить.

## 6. Tracking-by-Detection
Для кадра `t`:
1. Получить детекции `D_t`.
2. Предсказать состояния текущих треков.
3. Сопоставить детекции и треки.
4. Обновить сопоставленные треки.
5. Создать новые треки для несопоставленных детекций.
6. Удалить “устаревшие” треки.

## 7. Идея Kalman Filter (SORT)
Пример вектора состояния:
```text
x_t = [xc, yc, w, h, vxc, vyc, vw, vh]
```
Шаг прогноза:
```text
x_t_pred = F * x_(t-1)
```
Далее выполняется коррекция по измерению детектора.

## 8. Сопоставление Hungarian
Матрица стоимости между треками `i` и детекциями `j`:
```text
C[i, j] = 1 - IoU(track_i, det_j)
```
Алгоритм Hungarian находит паросочетание с минимальной суммарной стоимостью.

## 9. Прогноз при постоянной скорости
Простая модель движения:
```text
xc_t = xc_(t-1) + vxc_(t-1)
yc_t = yc_(t-1) + vyc_(t-1)
```
Это помогает удерживать ID при коротких окклюзиях.

## 10. Варианты функции стоимости
На основе IoU:
```text
C_iou = 1 - IoU
```
На основе расстояния:
```text
C_dist = sqrt((x1 - x2)^2 + (y1 - y2)^2)
```
В легковесных кастомных трекерах часто используют именно расстояние между центрами.
