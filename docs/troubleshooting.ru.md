# Устранение проблем

## Команда `uv` не найдена
Установите uv: https://docs.astral.sh/uv/

## Ошибка `No module named src`
Запускайте команды из корня репозитория (`AimVision/`) через:
```bash
uv run python ...
```

## Ошибка с весами модели
- Для обучения проверьте путь к базовой модели (например, `yolov8n.pt`).
- Для инференса/бенчмарка проверьте путь к `best.pt`.

## Ошибка OpenCV трекера (`TrackerCSRT_create` / `TrackerKCF_create`)
Синхронизируйте окружение:
```bash
uv sync
```

## Пустой benchmark report
- В папке с видео должны быть поддерживаемые форматы.
- Проверьте корректность весов и читаемость видео OpenCV.

## Низкий FPS
- Используйте более легкую модель (`yolov8n.pt`).
- Уменьшите `--imgsz`.
- По возможности запускайте на GPU.
