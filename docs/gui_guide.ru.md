# Руководство по GUI

## Запуск
```bash
uv run python scripts/run_gui.py
```

## Вкладки
- `Dataset`: извлечение кадров из видео.
- `Training`: запуск обучения YOLO.
- `Inference`: детекция на одном видео.
- `Benchmark`: сравнение трекеров.
- `Annotation Studio`: разметка датасета.

## Базовый сценарий разметки
1. Выбрать папку с изображениями (`datasets/frames/...`).
2. Выбрать папку для меток (`datasets/labels`).
3. Нажать `Load Images`.
4. Выбрать класс.
5. Нарисовать bbox мышью.
6. Нажать `Save Labels`.
7. Перейти к следующему кадру.

## Интеллектуальные функции
- `Auto-annotate with YOLO`: авторазметка текущего кадра по весам модели.
- `Smart Copy Box to Next Frame`: перенос последнего бокса на следующий кадр.
