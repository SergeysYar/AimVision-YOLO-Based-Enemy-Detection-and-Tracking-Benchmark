# Описание проекта

AimVision — портфолио-проект по компьютерному зрению для офлайн-анализа FPS-видео.

## Задача
По записанному геймплею:
- обнаруживать объекты (`enemy`, `teammate`, `weapon`, `head`),
- отслеживать их между кадрами,
- сравнивать трекеры на одинаковом наборе видео,
- формировать воспроизводимые отчеты.

## Входные данные
- Офлайн видеофайлы
- Наборы кадров/скриншотов
- Синтетические тренировочные ролики

## Выходные данные
- Аннотированные видео
- CSV-логи трекинга
- Markdown/CSV-отчеты с метриками

## Ограничения
- Только офлайн-обработка
- Без взаимодействия с запущенной игрой
- Без чтения памяти, инжектов и управления вводом

## Пайплайн
1. Подготовка и разметка датасета
2. Обучение YOLO-детектора
3. Tracking-by-detection
4. Бенчмарк трекеров
5. Подсчет метрик и генерация отчетов
